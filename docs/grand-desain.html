Project Akhir · Pemrograman Framework Laravel

IsyaratKita

Platform belajar Bahasa Isyarat Indonesia (BISINDO) untuk anak tunarungu, tuli, dan bisu — plus orang tua & guru.
meicha-isyarat Solo · Guest + Admin · Laravel 13

1 Tujuan

Membangun aplikasi web utuh (bukan sekadar CRUD) yang membantu anak dengan hambatan dengar/bicara belajar isyarat secara visual, bertahap, dan aman dikurasi.

Data yang dilihat Guest berasal dari database yang dikelola Admin. Desain konsisten, profesional, ramah anak, kontras tinggi.

2 Masalah & manfaat

  • Materi BISINDO untuk anak sering tersebar dan tidak terstruktur.
  • Orang tua/guru butuh kamus visual + panduan pendampingan.
  • Komunitas butuh agenda workshop yang terpusat.
  • Manfaat jangka panjang: inklusi, literasi isyarat, arsip konten yang bisa tumbuh.

3 Pengguna

Guest / Public

  • Beranda & pencarian
  • Kamus isyarat + filter kategori
  • Modul belajar & cerita visual
  • Artikel & agenda kegiatan

Admin

  • Auth + session + middleware
  • CRUD kategori, isyarat, modul
  • Upload gambar/video
  • Kelola artikel & event

5 Logo

Tanda tangan + hati di kotak rounded teal: dua pihak saling memahami tanpa suara. Warna teal (tenang, tumbuh) dan aksen coral (hangat, anak). Wordmark IsyaratKita — “isyarat milik kita bersama”.

6 Alur kerja Laravel (wajib dipahami, bukan hafalan)

Browser→ Route→ Middleware Auth/Role→ Controller→ Validation→ Model Eloquent→ View Blade→ Response

Fitur pendukung tiap tahap: Auth · Middleware · Session · Upload File · Search & Filter · Pagination · Flash message

7 Relasi data

usersid, name, email, role
categoriesname, slug, icon
signsword, meaning, level, category_id, status
mediasign_id, type, path
lessonstitle, level, order
lesson_signlesson_id, sign_id

eventstitle, date, place
1 kategori punya banyak isyarat. 1 isyarat punya banyak media. Modul belajar merangkai banyak isyarat (many-to-many).

8 Referensi template

Dilihat dulu, belum dipakai langsung (sesuai arahan dosen).

  • Guest: Kidkinder / tema education anak — https://themewagon.com/theme-price/free/
  • Admin: AdminKit atau Soft UI Dashboard (gratis)

10 Modul fitur (bukan CRUD terpisah)

  • Kamus Isyarat — jantung aplikasi: kata → gerakan → contoh kalimat.
  • Belajar Bertahap — modul per level, mengunci urutan pemahaman.
  • Cerita Visual — isyarat dirangkai jadi narasi pendek anak.
  • Keluarga & Guru — artikel pendampingan, tips komunikasi di rumah/sekolah.
  • Agenda — workshop BISINDO / kegiatan inklusi.
